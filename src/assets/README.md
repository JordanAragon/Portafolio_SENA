# Assets

Este directorio queda reservado para recursos reales del portafolio: capturas de proyectos,
imágenes optimizadas en WebP y videos cortos.

No se agregan imágenes de relleno ni recursos inventados. Cuando existan capturas definitivas de
AiDEN, Aragon Server e Inventario FNC, se pueden incorporar aquí sin cambiar la estructura de
componentes.
